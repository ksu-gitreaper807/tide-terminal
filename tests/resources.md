Priorities after this baseline:

1. Resolve or upgrade the two tracked dependency deviations, preserving the correct oracles. Investigate other malformed UTF-8 cases found by sustained fuzzing.
2. Integrate esctest2 behind a headless adapter with deadlines, capture the exact suite revision and emulator configuration, and classify every failure. Some VT extensions are outside Tide's present scope; unsupported features need named decisions rather than blanket ignores.
3. Run reviewed vttest visual/keyboard scenarios and real-app sessions on both native Wayland and accelerated Xwayland. Persist renderer/GPU/font versions with each capture. Add different iGPU vendors, DPI scales, IMEs/compose input and multi-monitor cases when those environments are available.
4. Measure source coverage, then mutation-test rules/privacy/attention logic. Set thresholds only from measured evidence and risk; a test-count goal can reward duplicate assertions.
5. Add repeated long-running stress jobs for output pressure, rapid resize/close cycles, disk errors, shell startup conflicts, suspend/resume and crash recovery boundaries. Actual system suspend, real biometric hardware, PAM policy changes, remote SSH containment and cross-platform behavior are not proven by the current synthetic local tests.

Keep external VT tools attached to the terminal being tested. Tide's ordinary CLI supervisor forwards its output to an outer terminal, which can also answer device queries; that setup can contaminate a conformance result. The Rust `terminal_queries.rs` tests avoid that ambiguity by owning both ends of the dialogue without sending query escapes to an outer display. A future external-suite adapter should do the same.

Append CLI references: [Bash redirections](https://www.gnu.org/software/bash/manual/html_node/Redirections.html) distinguishes append mode, stream merging, and redirection order; [Fish piping](https://fishshell.com/docs/current/language.html#piping) describes pipeline stream selection. These informed the explicit rejection of unavailable retrospective stream selectors. Tide's normalized terminal capture is a separate contract, not an emulation of every shell redirection expression.
