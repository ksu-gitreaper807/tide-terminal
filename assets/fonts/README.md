Tide embeds these unmodified fonts; a separate font installation is unnecessary.

| Font | Purpose | Notices |
| --- | --- | --- |
| Symbols Nerd Font Mono 3.5.1 | Complete Nerd Font icon catalogue, including Seti, Devicons, Font Awesome, Material Design, Octicons, Codicons, Powerline, weather and distribution logos | NerdFonts-LICENSE.txt and NerdFonts-README.md |
| DejaVu Sans 2.37 | Braille graphs, box drawing, blocks and navigation glyphs | DejaVu-LICENSE.txt |
| Noto Sans Symbols 2.003 | Additional technical and mathematical symbols | Noto-LICENSE.txt |
| Noto Sans Symbols 2 2.008 | Additional pictographs, arrows and Unicode symbols | Noto-LICENSE.txt |

Nerd Fonts was downloaded from the official v3.5.1 Symbols Only release:
https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1

DejaVu and Noto were copied from the installed ttf-dejavu and noto-fonts packages.
Versions, hashes, and upstream URLs are recorded in SOURCES.json.

The normal terminal text face and its cell metrics remain in use. Recognized
private-use Nerd icons use an explicit icon face, fitted and clipped to their
allocated cells, so older fallback fonts cannot substitute unrelated glyphs.
